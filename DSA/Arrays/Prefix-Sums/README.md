# Prefix Sums Pattern

## Concept
A Prefix Sum array stores the cumulative sum of elements from the start of the array. This allows for constant-time range sum queries.

## When to Use
- When you need to perform multiple sum queries over different ranges of an array.

## Time & Space Complexity
- **Pre-computation:** O(n)
- **Query:** O(1)
- **Space:** O(n)
