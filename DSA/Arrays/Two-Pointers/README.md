# Two Pointers Pattern

## Concept
The Two Pointers pattern uses two indices to traverse an array or string, typically moving towards each other or in the same direction to optimize time complexity from O(n²) to O(n).

## When to Use
- The input is sorted.
- Searching for pairs in a sorted array.
- Reversing an array or checking for palindromes.
- Removing duplicates from a sorted array.

## Time & Space Complexity
- **Time Complexity:** O(n)
- **Space Complexity:** O(1)
