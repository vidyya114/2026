# Binary Search Pattern

## Concept
Binary Search is a fast search algorithm that works on sorted arrays by repeatedly dividing the search interval in half.

## When to Use
- The input array is **SORTED**.
- You need to find the index of a specific target value.
- You need to find the boundary of a condition (e.g., first element > X).

## Time & Space Complexity
- **Time Complexity:** O(log n) - the search space is halved every step.
- **Space Complexity:** O(1) - constant space used for indices.
